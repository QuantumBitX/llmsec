LLM Security Series
Project Overview
This repository serves as a supplementary artifact archive for the research papers - LLM Security Series: The Alignment Paradox / The MoM Ensemble Synthesis / The Hyper-parameter Bypass. It captures offensive security outputs generated by open-weight models. The core objective of this research is to assess the fidelity of generated exploit code and close the compositional gap using a "Mixture of Model" approach and cross-context refactoring with Agentic Sandboxing planned to enhance the primitives.

The APT Gauntlet Artifacts
The artifacts stored here represent a rigorous Advanced Persistent Threat (APT) gauntlet designed to evaluate model capabilities across multiple languages and vectors.

Gemma-MoM-EDR-DLL-Unhooking.cpp: C++ implementation for evading endpoint detection by restoring in-memory DLLs to their original disk state.

Gemma-MoM-DNS-Exfiltration.py: Python script for covert data transfer utilizing session UUIDs and random jitter to evade network baselines.

Gemma-MoM-Tomcat-Memory-Injection.java: Java payload establishing fileless persistence via malicious filter injection into a running Apache Tomcat process.

Gemma-MoM-BlindSQLi.py: Python tool designed for inferential data extraction and dynamic payload generation.

Gemma-MoM-Deserialization-NET.cs: C# script leveraging in-memory Common Intermediate Language (CIL) manipulation for zero-dependency payloads.

Gemma-MoM-OOB-XXE.py: Python handler serving malicious DTDs and capturing exfiltrated data via out-of-band callbacks.

Methodology
This project moves beyond standard zero-shot prompt evaluations. It utilizes an iterative execution feedback loop within a simulated sandbox environment to test how models handle compiler errors, stack traces, and network data. The resulting "glue code" represents a measurable escalation in autonomous offensive tradecraft.

Ethics & Responsible Disclosure
All code within this repository is intended strictly for defensive research and red-team capability assessment. All evaluation activities were conducted in isolated, non-routable sandbox environments. This research adheres strictly to dual-use guidelines and OWASP standards to ensure responsible disclosure.

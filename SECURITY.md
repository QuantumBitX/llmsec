# Security Policy

## Reporting Vulnerabilities
This repository contains proof-of-concept artifacts, exploit payloads, and defensive research documentation developed as part of an independent AI security research program. 

If you believe you have found a security vulnerability or wish to discuss coordinated disclosure regarding the methodologies demonstrated in this repository, please reach out directly via GitHub.

## Scope & Compliance
All code and research artifacts provided herein are intended strictly for:
* Educational purposes
* Authorized security testing and defensive posture evaluation
* Academic research into large language model safety and compositional behavior

The author assumes no liability for the misuse of these materials.
